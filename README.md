# Robo desvia obstáculos 
Projeto de um robô que consegue desviar de obstáculos usando sensores de chave fim de curso

## 📌 Descrição
Este projeto tem como objetivo **desenvolver um robô autônomo** capaz de **detectar e desviar de obstáculos** utilizando **sensores de chave fim de curso**.  
O foco principal é **aplicar conceitos de eletricidade, eletrônica e lógica de funcionamento** em um projeto **prático, colaborativo e educativo**.
